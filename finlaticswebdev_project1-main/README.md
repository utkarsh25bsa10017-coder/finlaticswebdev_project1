# Utkarsh — Personal Portfolio Website

A futuristic, minimal personal portfolio built for project certification.

## Features

- **Hero Section** — Profile photo shifted left with intro text
- **About** — Personal background with two info cards (Endurance Running & Current Pursuits)
- **Qualification** — Class 10th (89%), Class 12th (74%) from St. Therese's School, 2nd year at VIT Bhopal
- **Projects** — FPV race drones and Team Vortex / SAE AeroDesign West
- **Contact Form** — Name, email, subject, and message fields
- **Responsive Design** — Mobile hamburger menu, flexible grids, and adaptive typography
- **Footer** — "WHO DARES WINS" in golden Algerian font

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Custom CSS (`styles.css`)
- Orbitron & Rajdhani fonts (Google Fonts)
- Algerian font (CDN Fonts)

## Getting Started

```bash
npm install
npm start
```

Open `http://localhost:3000` or open `index.html` directly in a browser.
