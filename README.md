# Utkarsh — Personal Portfolio Website

A futuristic, minimal personal portfolio built for project certification. Showcases academic qualifications, personal achievements, and current pursuits.

## Features

- **Hero Section** — Profile photo with dark maroon futuristic layout
- **About** — Personal introduction and background
- **Qualification** — Class 10th (89%), Class 12th (74%) from St. Therese's School, and current studies at VIT Bhopal
- **Hobbies** — Two dark grey cards covering endurance running and FPV drones / aerospace engineering
- **Navigation** — Sticky top menu linking to About, Qualification, and Hobbies
- **Footer** — "WHO DARES WINS" motto in golden Algerian font
- **Responsive Design** — Mobile-friendly layout using Tailwind CSS

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Custom CSS (`styles.css`)
- Orbitron & Rajdhani fonts (Google Fonts)
- Algerian font (CDN Fonts)

## Project Structure

```

    └── utkarsh-profile.png
```

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the local development server:

```bash
npm start
```

3. Open `http://localhost:3000` in your browser.

Alternatively, open `index.html` directly in a browser — no build step required.

## Deployment

This static site can be deployed to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or GitHub Pages.
